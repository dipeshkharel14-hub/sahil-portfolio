# Sahil Lama — Portfolio (GitHub Pages)
Static site: no build step. Works as-is on GitHub Pages.

## Deploy
1. Upload everything in this folder to the repo root (keep `.nojekyll`; keep `CNAME` if you use a custom domain).
2. Put Sahil's photo in the repo root as `sahil.jpg` (same folder as `index.html`).
3. Settings → Pages → Deploy from a branch → `main` / `(root)`.

## Customize
- `main.js` → `CONFIG`: `portrait`, `email`, `site`, `siteLabel`, `github`, `linkedin` (empty ones are hidden).
- Compress `sahil.jpg` (squoosh.app) so it loads fast on phones.

## Behaviour
- 10 autonomous pointers on desktop (5 on phones) drag selection boxes to open every word, image and button, then auto-scroll through the page. They pause when the visitor scrolls, moves or types. TAKE CONTROL unlocks everything.
- Sound is off by default. Press Ctrl/⌘+K for the command palette.
